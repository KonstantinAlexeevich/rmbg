# 06. Интерфейс студии

## Общая раскладка

Одна вкладка, три зоны:

```
+-----------------------------------------------------------------------+
| Шапка: логотип | бейдж бэкенда | статус модели                         |
+--------------------------------------------+--------------------------+
|                                            |  Панель настроек:        |
|  Грид карточек  или  просмотр «до/после»   |   - Край маски           |
|  (взаимоисключающе в основной области)     |   - Список пресетов      |
|                                            |   - Настройки пресета    |
|                                            |   (+ цель правки, если   |
|                                            |    открыт просмотр)      |
+--------------------------------------------+--------------------------+
| Нижняя панель: прогресс пачки / экспорта                               |
+-----------------------------------------------------------------------+
```

Панель настроек фиксированной ширины справа, основная область тянется. На узких окнах
панель сворачивается в выдвижную.

## Пустое состояние

Крупная зона перетаскивания на весь грид: «Перетащите изображения сюда», кнопка
«Выбрать файлы», подсказка про вставку из буфера. Ниже одной строкой — что после
разовой загрузки модели расширение работает офлайн и ничего не отправляет на сервер.
Это главное отличие от онлайн-сервисов, и говорим о нём сразу.

## Загрузка модели

При открытии студии фоном стартует детект бэкенда и загрузка нужного варианта весов
(см. [03-inference.md](03-inference.md)). Состояния в шапке или нижней панели:

- качается — полоса прогресса с процентами и объёмом («Загрузка модели: 42 МБ из 176 МБ»),
  кнопка «Отменить»;
- ошибка сети / офлайн — текст «Не удалось загрузить модель» и кнопка «Повторить»;
- хэш не совпал — то же, после исчерпания зеркал;
- кэш вытеснен браузером — отдельный текст «Модель удалена браузером, нужно скачать снова»
  и кнопка «Скачать»;
- готова — индикатор скрывается.

Кнопка «Обработать» активна всегда, но при нажатии до готовности ассета показывает
«модель загружается» (или «модель готовится», если веса уже есть, а прогрев ещё идёт)
и стартует очередь по готовности. Отдельного блокирующего экрана загрузки нет.

## Карточка изображения

Содержит: превью (шахматка под прозрачностью), имя файла, статус, чекбокс выбора.
По наведению — действия: увеличить, повторить, удалить, скачать отдельно.

Статусы и их вид:

- `queued` — приглушённое превью оригинала, значок очереди.
- `segmenting` — превью оригинала, индикатор прогресса поверх. Второй проход по объекту
  отдельным статусом не выделяем: для пользователя это та же стадия, просто дольше.
- `composing` — то же, но быстро; отдельный текст не нужен, хватает индикатора.
- `done` — превью результата.
- `failed` — красная рамка, короткая причина, кнопка «Повторить».

Предупреждение «фон не найден» (пустая маска) показывается как жёлтая плашка на карточке,
результат при этом всё равно формируется. Карточка со слепком для активного пресета
помечается значком переопределения.

## Просмотр «до/после»

Клик по карточке (или Enter / кнопка «Увеличить») открывает просмотр **в основной
области**: грид скрывается, шапка и боковая панель настроек остаются. Так можно крутить
край и layout, глядя на крупный кадр.

Слайдер с вертикальным разделителем сравнивает «До» и «После». Оба кадра собираются
на лету из одного эффективного пресета (`loadCompareUrls`), чтобы не расходиться при
stale:

- «После» — cutout + `composeOnCanvas` (холст, поля, привязка, фон);
- «До» при `sizeMode === 'fixed'` — тот же `layoutSubject` (scale и смещение bbox→dest),
  но рисуется весь оригинал (`composeCompareBefore`), чтобы субъект совпал на слайдере,
  а края исходника продолжались в поля холста; при `original` — копия исходника.

Размер сцены вписывается в доступную область через `ResizeObserver` с сохранением
пропорций холста (и для портрета, и для ландшафта). Пока результат устарел и
пересчитывается — превью затемнено. Стрелки ←/→ листают соседние карточки, Esc или
кнопка «К сетке» закрывают просмотр.

В панели при открытом просмотре появляется полоса с именем файла и кнопкой
«Переопределить для этой картинки». После создания слепка контролы «Край маски»
и layout-поля пресета (размер, фон, ширина/высота, поля, привязка, «не увеличивать»)
правят слепок этой картинки в текущем пресете; секции подсвечиваются. Название, формат
и качество остаются пресетными и в режиме слепка скрыты. «Вернуть к пресету» удаляет
слепок.

## Панель настроек

Пресеты:

- список пресетов: клик делает активным (превью студии);
- добавить (дубликат активного), удалить (нельзя удалить последний), переименовать;
- при нескольких пресетах перед ZIP открывается выбор `exportPresetIds`.

Настройки активного пресета (одна форма; при слепке — эффективные значения):

- размер: «Оригинальный» / «Заданный» (`sizeMode`);
- фон: переключатель «Прозрачный / Однотонный»; при «Однотонный» — палитра и цвет;
- при «Заданный»: ширина и высота холста, поля (%), привязка по вертикали,
  галка «не увеличивать объект»;
- формат вывода и качество (качество скрыто для PNG; в режиме слепка не редактируются).

Край маски: три ползунка (порог, поджатие, сглаживание) с кнопкой «Сбросить». Каждый
подписан тем, что он делает, а не термином: «Убрать светлый ореол», а не «Erode».
Край по умолчанию общий для всех пресетов; при слепке на картинке — свой.

Смена активного пресета или правка его полей помечает результаты устаревшими
(поэлементно, с учётом слепков) и запускает перекомпозицию с дебаунсом 200 мс.
Открытая в просмотре картинка пересчитывается первой. Отдельной кнопки «Применить» нет.

Внизу панели: «Скачать» (ZIP выбранных done) и «Очистить» (новая сессия).

## Прогресс и отмена

Пока идёт фоновая загрузка модели или её прогрев, кнопка «Обработать» активна, но при
нажатии показывает соответствующее состояние и стартует очередь по готовности.

Нижняя панель показывает «Обработано X из Y», оценку оставшегося времени по среднему
времени последних прогонов и кнопку «Остановить». Первое изображение на WASM-пути в
среднее не включается: оно играет роль прогрева и заметно медленнее остальных. Остановка не отменяет текущее
изображение (прогон модели прервать нельзя), а перестаёт брать новые из очереди.

## Бейдж бэкенда

В шапке: «GPU» или «CPU». По клику — панель диагностики из [03-inference.md](03-inference.md).
Если произошёл фолбэк с WebGPU, при первом переключении показываем одноразовое уведомление
с причиной: пользователь должен понимать, почему стало медленно.

## Клавиатура и доступность

- `Ctrl/Cmd + V` — вставить изображение из буфера.
- `Ctrl/Cmd + A` — выбрать все карточки.
- `Delete` — удалить выбранные.
- `Enter` на карточке — открыть просмотр.
- Все интерактивные элементы достижимы табом, у иконочных кнопок есть `aria-label`,
  видимый фокус не убираем.

## Тексты и локализация

Интерфейс на русском. Все строки лежат в одном словаре (`ru`), английский добавляется
как второй словарь без изменений в компонентах. Формат сообщений об ошибках: что
случилось и что делать, без кодов и стектрейсов (стектрейс — в консоль и в диагностику).
