# Спецификация: rmbg — Chrome-расширение для удаления фона

Расширение Chrome (Manifest V3), которое удаляет фон с изображений локально в браузере:
ISNet через `onnxruntime-web`, WebGPU как основной путь и WASM как фолбэк. Пользовательские
изображения никуда не отправляются; единственный сетевой запрос — разовая загрузка файла
весов модели с фиксированного адреса.

## Статус

Спецификация отражает текущую реализацию студии: экспорты (`Preset` в коде) с
`sizeMode`, слепки на изображение (`ItemOverride`), просмотр «до/после» в основной
области, боковая панель «край → exports» (в просмотре плюс шапка изображения),
действия сессии в нижней панели (Export ZIP, Clear, Add images), EN-first
локализация и lucide-иконки, IndexedDB v2. Термины UI — в [09-glossary.md](09-glossary.md).
Раздел «Открытые вопросы» — то, что ещё можно уточнить; закрытые вопросы переносятся
в [08-decisions.md](08-decisions.md).

## Инварианты, которые не нарушаем

1. Ни один байт пользовательских изображений не покидает устройство. Единственный сетевой
   запрос за всё время жизни расширения — разовая загрузка файла весов модели с
   зафиксированного адреса (пин на коммит Hugging Face) с проверкой SHA-256. После неё
   работа полностью офлайн: ни к своим серверам, ни к CDN запросов нет.
2. Все исполняемые ресурсы (JS, WASM) лежат внутри пакета расширения. Это требование
   политики Chrome Web Store о remotely hosted code. Веса модели (`.onnx`) — файл данных,
   а не код; они скачиваются в рантайме и кэшируются локально.
3. Расширение не запрашивает доступ к содержимому веб-страниц: ни `content_scripts`, ни
   host permissions (если CORS Hugging Face позволяет — см. запасную ветку в
   [02-architecture.md](02-architecture.md)).
4. Дорогая операция (сегментация) выполняется один раз на изображение; смена фона,
   экспорта, края или слепка пересчитывает только композицию.
