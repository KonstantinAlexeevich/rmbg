# 01. Продукт: цели, сценарии, объём

## Задача

Пользователь (продавец на маркетплейсе, фотограф, дизайнер) имеет пачку фотографий товара.
Ему нужно получить те же фотографии без фона — прозрачные PNG либо на однотонном фоне,
приведённые к одному размеру холста и одной геометрии, и скачать всё одним архивом.

## Целевой пользователь и его боль

- Онлайн-сервисы удаления фона просят загрузить фото на сервер, ограничивают количество
  бесплатных изображений и режут разрешение.
- Ручная обработка в редакторе — минуты на кадр.
- Обработка нужна пачками по 10-100 кадров с одинаковыми настройками.

## Ключевой сценарий (happy path)

1. Пользователь нажимает иконку расширения — открывается вкладка «студия». Фоном
   определяется бэкенд и при необходимости скачивается нужный файл весов модели
   (прогресс в интерфейсе).
2. Перетаскивает 30 фотографий в окно (или выбирает через диалог, или вставляет из буфера).
3. Выбирает фон: прозрачный или однотонный цвет.
4. Настраивает пресет вывода: размер холста, поля вокруг товара, привязку по вертикали,
   формат и качество файла.
5. Нажимает «Обработать». Если модель ещё качается — ждёт готовности; затем видит прогресс
   по каждой карточке; готовые превью появляются по мере обработки.
6. Просматривает результат, при необходимости меняет фон или пресет — пересчёт мгновенный,
   без повторного прогона модели.
7. Нажимает «Скачать ZIP» — получает архив с обработанными файлами.

## Дополнительные сценарии

- Первый запуск без сети — модель не скачивается; интерфейс показывает ошибку и кнопку
  «Повторить». Обработка недоступна, пока веса не загружены.
- Повторный запуск — веса берутся из Cache Storage, сети нет.
- Часть изображений не удалось обработать (битый файл, нехватка видеопамяти) — они помечены
  ошибкой, остальные обработаны; есть кнопка «повторить» для отдельной карточки.
- Пользователь закрыл вкладку и вернулся позже — сессия восстанавливается из IndexedDB
  вместе с уже посчитанными масками.
- Пользователь снял выделение с части карточек — в архив попадают только выбранные.
- У пользователя нет WebGPU — качается q8-вариант, обработка идёт на WASM, интерфейс честно
  показывает режим и то, что будет медленнее.

## Объём версии 1

Входит:

- Пакетная загрузка изображений: drag & drop, выбор файлов, вставка из буфера обмена.
- Форматы на входе: PNG, JPEG, WebP (всё, что декодирует `createImageBitmap`).
- Удаление фона моделью ISNet, WebGPU с фолбэком на WASM; веса скачиваются один раз при
  первом открытии студии и кэшируются локально.
- Фон: прозрачный либо однотонный цвет.
- Настройки уточнения края маски: порог альфы, сглаживание (feather), поджатие маски (erode).
- Один произвольный пресет кропа с сохранением в настройках (размер холста, поля, привязка,
  формат вывода и качество).
- Просмотр «до/после» для отдельного изображения.
- Экспорт пачки в ZIP, а также скачивание отдельного файла.
- Восстановление сессии из IndexedDB.
- Интерфейс на русском с заготовкой под второй язык.

Не входит в v1 (осознанно отложено):

- Готовые пресеты маркетплейсов (Wildberries, Ozon, Amazon и прочие) — добавляем позже,
  когда механика произвольного пресета обкатана. Модель данных сразу это учитывает.
- Градиентный фон, фоновая картинка, тени и отражения под объектом.
- Направляемая фильтрация края (притягивание маски к цветовым границам оригинала) —
  самый сильный из оставшихся рычагов качества кромки, но сначала смотрим на результат
  без неё.
- Ручная доводка маски кистью, восстановление/удаление областей.
- Контекстное меню «убрать фон с этой картинки» на любой веб-странице (потребует
  content script и host permissions — сознательно не берём в v1).
- Пакетное переименование по шаблону, водяные знаки, апскейл.
- Синхронизация настроек между устройствами.

## Критерии готовности v1

- На машине с WebGPU: изображение 3000x4000 обрабатывается менее чем за 2 секунды
  (без учёта первичной загрузки модели), а кадр с мелким объектом, где включается второй
  проход, — менее чем за 4. Пачка из 30 кадров обрабатывается без роста потребления памяти
  до вкладки-убийцы.
- На машине без WebGPU: обработка идёт и завершается, интерфейс не блокируется.
- Повторная композиция всей пачки при смене цвета фона — менее 1 секунды на 30 кадров.
- После загрузки модели сетевых запросов нет (проверяется в DevTools: единственные запросы —
  к Hugging Face при первом скачивании весов; пользовательские изображения в Network не
  появляются никогда).
- Расширение устанавливается как распакованное и собирается в ZIP, проходящий валидацию
  манифеста. Размер пакета без весов — порядка 5 МБ.
